# NEXORA — Futuristic E-Commerce HTML Template

**NEXORA** is a premium, futuristic multi-page e-commerce HTML5 website template engineered for next-generation tech, audio, wearables, gaming gear, and lifestyle-tech storefronts. Built with semantic HTML5, modern CSS3 custom properties, and modular vanilla JavaScript, NEXORA delivers a tactile cyberpunk luxury experience with zero frameworks and zero dependencies.

---

## Key Features

- **13 Complete Multi-Page HTML Templates**: Full end-to-end storefront flow from discovery to checkout.
- **Zero Runtime Dependencies**: No jQuery, no React, no external libraries required. Pure vanilla ES-style modular JavaScript.
- **Functional Client-Side Storefront UI**:
  - Live shopping cart drawer and dedicated cart page with real-time subtotal, 8% tax calculation, and free-shipping progress tracker ($150 threshold).
  - Promo coupon redemption engine with built-in discount types (percentage, fixed amount, free shipping).
  - Bookmarkable wishlist with interactive state and move-to-cart functionality.
  - Multi-criteria product catalog filtering (by category, price range, rating, and on-sale status) with instant client-side execution.
  - Instant live search overlay with search keyword matching across product names, descriptions, and tags.
  - Quick-view product modal with real-time stock indicator, image gallery zoom, color swatches, and size variation pickers.
  - Interactive multi-step checkout demonstration with comprehensive client-side form validation and order confirmation state.
- **Modern Cyberpunk / Sci-Fi Luxury Design**:
  - Deep dark mode color system (`#090B12`, glowing violet `#A855F7`, electric cyan `#00E5FF`, emerald green `#34D399`).
  - Cohesive design token architecture declared in CSS `:root` for effortless rebranding.
  - Fluid clamp-based responsive typography and micro-animations with full `prefers-reduced-motion` compliance.
- **100% Responsive & Cross-Browser Tested**: Tested across 320px, 375px, 390px, 430px, 768px, 1024px, 1280px, 1440px, and 1920px viewports. Zero horizontal scroll on any screen size.
- **Accessible & SEO Ready**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<footer>`), keyboard navigation with skip-link, W3C valid markup, Open Graph tags, Twitter cards, `robots.txt`, and `sitemap.xml`.
- **Self-Hosted Open Source Fonts**: Syne, Inter, and JetBrains Mono fonts included under SIL Open Font License 1.1 with zero external render-blocking font requests.
- **Vector Icon Sprite**: Inlined Lucide SVG icons (ISC license) for optimal performance and zero icon font flicker.
- **Extensive Offline Documentation**: Searchable, responsive HTML documentation covering installation, color customizations, product data management, and backend integration recipes.

## Included Pages (13 HTML Files)

1. `index.html` — Homepage with hero showcase, category spotlights, featured drops, bundle showcases, reviews, and newsletter.
2. `shop.html` — Full catalog listing with faceted filtering, multi-column grid/list layout switch, and pagination.
3. `product.html` — Dynamic product details page with gallery zoom, color/size variants, tabs, and related recommendations.
4. `categories.html` — Visual category directory with item counters and explore links.
5. `cart.html` — Interactive shopping cart with quantity controls, shipping calculator, and coupon codes.
6. `checkout.html` — Multi-step checkout form demonstration with real-time validation and order confirmation.
7. `wishlist.html` — Saved products dashboard with move-to-cart actions and empty state.
8. `about.html` — Company story, engineering philosophy, timeline, and leadership team.
9. `contact.html` — Contact form with instant client-side validation, direct support details, and map graphic.
10. `faq.html` — Categorized accordion with direct anchor link support (`#orders`, `#shipping`, `#returns`, `#product`, `#privacy`).
11. `blog.html` — Technology and lifestyle journal grid with featured post and category filtering.
12. `blog-details.html` — Editorial article layout with typography styles, blockquotes, and social sharing hooks.
13. `404.html` — Futuristic error page with quick search and recovery links.

## Important Disclosures

### E-Commerce & Payment Processing
> **Demonstration Only:** NEXORA is a static front-end HTML/CSS/JavaScript template. The shopping cart, wishlist, coupon system, and checkout are client-side demonstrations persisted in your browser's `localStorage`. No actual payments are processed, no cards are charged, and no customer data is transmitted to an external server. To accept live orders and process payments, connect the template to your chosen backend, payment gateway (e.g. Stripe, PayPal, Lemon Squeezy), or e-commerce platform. Integration points are clearly marked throughout the code.

### Imagery & Media Assets
> **Demo Photography Not Included:** The product, model, lifestyle, and environment photography shown in the live preview demo and promotional screenshots is for demonstration and presentation purposes only and is **not included** in the customer download. The download package contains high-resolution branded placeholder images with identical file names and pixel dimensions, allowing the template to render immediately out of the box while making it effortless to drop in your own photos.
