NEXORA — Futuristic E-commerce HTML Template · v1.0.0 · by TemplateFlux
=======================================================================

QUICK START
1. Open documentation/index.html in your browser and read "Installation".
2. Preview locally: inside the template/ folder run   python3 -m http.server 8080
   then visit http://localhost:8080  (or simply open template/index.html).
3. Upload the CONTENTS of template/ to your web host. No build step is needed.

CUSTOMISE
- Colours, spacing, radii, shadows:  template/assets/css/style.css → section 02 DESIGN TOKENS
- Products, prices, coupons, store settings:  template/assets/js/data.js
- Shared header / footer: marked with "(shared)" comments in each HTML page

IMPORTANT
- Checkout & payment are DEMO ONLY. Connect a real payment provider before selling
  (search the JS for "INTEGRATION POINT").
- Demo images are not included; placeholders with identical names and sizes ship instead.
